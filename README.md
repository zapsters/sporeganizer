# Sporeganizer

Sporeganizer is a fun and engaging homework tracking and productivity app with a mushroom theme! It helps users stay organized and on top of their homework assignments, all while offering a unique, visually pleasing interface.

> _Built with love for my partner, who adores mushrooms <3_

Check it out live at: [Sporeganizer.com](https://sporeganizer.com/)

## Key Features

- **Homework Tracking**: Easily manage and keep track of homework assignments with due dates and descriptions.
- **Mushroom-Themed Design**: Enjoy a playful, mushroom-themed interface that makes productivity a bit more fun.
- **Cross-Device Compatibility**: The app is fully responsive, ensuring it works seamlessly across mobile, tablet, and desktop devices.
- **Ongoing Development**: Many exciting features are planned for future releases, including notifications and task prioritization.

> This project is my first venture into backend development and serves as a personal learning experience alongside my college coursework. I am continuously working to improve it and add new features.

## Technologies Used

- **Svelte**: A modern and fast JavaScript framework for building interactive user interfaces.
- **HTML**: Provides the structure and layout for the app.
- **CSS & SASS**: For responsive, clean styling to ensure a smooth user experience across devices.
- **JavaScript / JQuery**: Enhances interactivity and provides form validation to ensure data integrity.
- **Firebase**: Utilized for authentication, cloud functions, and Firestore database to manage user data and homework assignments.
- **Firebase Emulator**: Used for local development and testing to simulate a production environment.

## Future Enhancements

- **Assignment creation & management**: In the works...
- **Due Date Reminders**: Push notifications or email reminders for upcoming homework deadlines.
- **Task Prioritization**: Implement a system for categorizing and prioritizing homework tasks to help users focus on what’s most important.
